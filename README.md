# Widget orologio a ribalta

Widget Android per la Home: ore e minuti in due quadrati scuri, stile digitale a segmenti.
Nessun servizio in background: l'ora è aggiornata dal sistema (TextClock).

- Colori: `app/src/main/res/values/colors.xml`
- Grafica: `app/src/main/res/layout/clock_widget.xml`
- Cifre a 7 segmenti disegnate dal codice; giorno in Inter (SIL Open Font License)

L'APK viene compilato da GitHub Actions a ogni push e pubblicato nelle Releases.
